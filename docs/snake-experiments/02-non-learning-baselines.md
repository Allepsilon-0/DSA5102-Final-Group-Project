# 实验 2 非学习基线

## 实验目的

用 Pure Random、Safe Random 和 Greedy 建立问题下界、合法动作带来的改进幅度，以及人工规则的性能上限。

## 在实验链中的位置

该实验位于正式 RL 之前，为 Tabular Q、DQN 和所有改进方法提供可解释参照，并提供“为何需要学习长期价值”的失败案例。

## 方法

- Pure Random：三个相对动作等概率抽样，不预先过滤危险动作。
- Safe Random：仅在下一步不立即碰撞的动作中随机选择；无安全动作时按固定规则处理。
- Greedy：优先缩短蛇头与食物的距离，同时进行一步碰撞检查。
- 每种策略使用相同测试 seeds 运行至少 100 局。

## 控制变量

环境、棋盘、动作定义、终止规则、测试 seeds 和评估局数保持一致。Pure Random 与 Safe Random 必须分开命名，不能合并为一个“Random”。

## 希望达成的结果

- Pure Random 给出可复现的最低参照。
- Safe Random 显示仅避免一步死亡能带来的收益。
- Greedy 明显强于随机策略，但在长蛇身、死胡同和自我包围局面中出现性能天花板。
- 收集至少一个 Greedy 局部最优失败案例，为后续长期价值学习提供动机。

## 必须产出

- score 与 episode length 的箱线图；
- 均值、标准差、中位数与四分位数表；
- 墙撞、自撞和超时的比例；
- 典型成功和失败轨迹。

## 继续条件

三种基线行为符合直觉且结果可复现；若 Random 异常强或 Greedy 异常弱，应优先检查环境或策略实现。
