# 实验 7 条件扩展 Dueling DDQN 或 PPO

## 实验目的

在核心实验完成且预算仍充足时，检验网络结构分解或跨算法范式是否提供额外收益。

## 在实验链中的位置

这是条件实验，不是默认必做。DQN、DDQN、多 seed 和状态表示实验未完成时，应跳过本实验，优先保证核心证据质量。

## 方案选择

### 方案 A Dueling DDQN

将 Q 输出拆为状态价值 `V(o)` 与动作优势 `A(o,a)`，研究其是否提升样本效率。Snake 只有三个动作，因此优势不保证明显。

### 方案 B PPO

使用 actor-critic 与 clipped objective，提供与 value-based 方法不同的算法家族对照，但 on-policy 训练通常需要更多环境交互与调试。

两者只能选择一个作为扩展，以免实验矩阵失控。若研究重点是状态信息瓶颈，优先 Dueling 或直接不增加扩展；若重点是跨范式比较，选择 PPO。

## 控制变量

Dueling 与 DDQN 应保持相同 target、训练预算和近似参数量；PPO 则使用相同环境交互预算、seeds 和评估局面，并清楚记录算法特有调参预算。

## 希望达成的结果

- Dueling 可能提高曲线 AUC 或达到目标 score 的速度，但最终 score 也可能不变。
- PPO 可能获得稳定随机策略，但样本效率未必优于 off-policy DDQN。
- 无提升也应报告，并据此说明模型复杂度不是当前主要瓶颈。

## 必须产出

- 预先说明选择哪一种扩展及原因；
- 与最接近核心基线的公平曲线和成本对比；
- 参数量、训练时间、环境交互量和最终 score；
- 保留或舍弃该扩展的证据化结论。

## 启动条件

DQN 与 DDQN 已稳定，核心方法至少完成 3 个 seeds，状态表示实验已有结果，且剩余预算不会危及奖励消融、终评和视频。
